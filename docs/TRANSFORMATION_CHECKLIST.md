## 2. معايير القبول الفني لكل مرحلة (Acceptance Criteria per Phase)

### المرحلة 5A: رموز التصميم (Design Tokens)
- [ ] إضافة ألوان `ivory`, `navy`, `petrol`, `burntOrange`, `editorial` إلى `tailwind.config.js`.
- [ ] تحديث المتغيرات الجذرية في `src/index.css` مع الحفاظ على خط `IBM Plex Sans Arabic` ودعم RTL.
- [ ] التحقق من مرور `npm run lint` بنجاح دون أي خطأ.

### المرحلة 5B: الهيدر والبحث (Header & Navigation)
- [ ] تصميم الهيدر بخلفية بيضاء نقية مع تفاصيل كحلية وبترولية أنيقة.
- [ ] الحفاظ على البحث التنبئي الحي واقتراحات المنتجات المطابقة للغة العربية.
- [ ] الحفاظ على أزرار سلة التسوق، قائمة المفضلة، تسجيل الدخول، واختيار المحافظة.
- [ ] التحقق من عمل الميجا منيو المنسدل بدقة على سطح المكتب وقائمة الهامبرغر على الهواتف.

### المرحلة 5C: بانر الهيرو التحريري (Hero Carousel)
- [ ] إضافة البطاقة التحريرية العائمة (Floating Editorial Card) المشتملة على العنوان والوصف والـ CTA.
- [ ] الحفاظ على مؤقت التقليب التلقائي وإمكانية الإيقاف المؤقت عند تمرير المؤشر (Pause on hover).
- [ ] الحفاظ على دعم السحب بالإصبع (Touch swipe) على شاشات الجوال.

### المرحلة 5D: شبكة الأقسام (Category Discovery Grid)
- [ ] تصميم بطاقات الأقسام بأسلوب تحريري أنيق وبسيط يعرض صورة القسم واسمه وتصنيفاته الفرعية.
- [ ] توفير بطاقة نهاية مميزة (Accent End Card) لـ "جميع الأقسام" للتوجيه المباشر لـ `/shop`.
- [ ] التأكد من أن رابط مركز الطباعة يتوجه تلقائياً إلى `/print-center`.

### المرحلة 5E: بطاقات المنتجات (Product Cards)
- [ ] إطار صورة بلون عاجي خفيف مع تبديل سلس عند الـ hover بين الصورة الأساسية والثانوية.
- [ ] زر إضافة للسلة بنمط البترولي العميق مع تأثير الحركة السلس عند الإضافة.
- [ ] دعم فتح نافذة الخيارات السريعة (Quick View) في حال وجود بدائل أو مقاسات.
- [ ] شارة خصم واضحة باللون البرتقالي المحروق أو البترولي.

### المرحلة 5F: الرفوف ومساحات الخدمات (Shelves & Services)
- [ ] خطوط رفوف تحريرية ناعمة مع شارات فرعية أنيقة.
- [ ] بطاقة مركز الطباعة الرقمي بتدرج كحلي أنيق وخدمات واضحة وروابط حاسبة التكلفة.
- [ ] قسم قصة المتجر والضمانات مع إبراز أعمدة الثقة والأرقام التحريرية الفاخرة.

### المرحلة 5G: الفوتر (Footer)
- [ ] خلفية كحلية عميقة `#002D3A` مع خطوط فواصل عاجية رقيقة.
- [ ] المحافظة على جميع أرقام التواصل وروابط الواتساب وصفحات الشروط والسياسات.
