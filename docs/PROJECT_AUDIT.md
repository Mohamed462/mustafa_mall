**المرجع التصميمي الأساسي:** B.TECH (https://btech.com/ar) — مع تكييف الهوية لـ مول المصطفى.

### 1. ملخص الفحص الميداني لحالة المشروع (Initial State Audit)

1. **حالة الكود والاعتماديات:** المستودع لا يحتوي على كود سابق، مما يمنحنا حرية بناء أساس متين ومعياري يتطابق 100% مع معايير هندسة البرمجيات والتجارة الإلكترونية المعاصرة.
2. **شعار وهوية مول المصطفى:** لم يتم العثور على ملفات صور مسبقة لـ "مول المصطفى" في النظام. وفقاً للبند 3 من المتطلبات، تم تصميم هوية رقمية وشعار SVG فكتور رسمي بديل ومؤقت ومميز بالخط العربي الأصيل وألوان المول المصرية الرصينة (الكحلي الملكي `#0b2545` مع الذهبي الوقور `#f59e0b` والأبيض الناصع `#ffffff`) مع توفير ميزة رفع واستبدال الشعار من لوحة التحكم في أي وقت.
3. **فحص المرجع التصميمي (B.TECH Architecture Audit):**
   - تم فحص ومعاينة موقع `https://btech.com/ar` حياً.
   - البنية التصميمية تعتمد على:
     - اتجاه RTL أصيل مع خط عربي واضح ومتناسق (Noto Sans Arabic / Cairo).
     - شريط علوي موحد يحتوي على: قائمة الفئات المنسدلة (Mega Menu)، محرك البحث البارز "بتدور على إيه؟"، اختيار وجهة التوصيل، روابط المفضلة، حسابي، وسلة المشتريات التفاعلية مع عداد ديناميكي.
     - شريط الفئات السريعة وروابط الأقسام.
     - قسم بانرات رئيسي (Hero Carousel) بنسب أبعاد متجاوبة (3:1 على الشاشات الكبيرة و 1.5:1 على الموبايل).
     - شبكة تصفح الفئات الرئيسية (Category Discovery Grid) ببطاقات ناعمة الملمس وأيقونات/صور واضحة.
     - صفوف منتجات منتقاة (عروض حصرية، أحدث المنتجات، الأكثر مبيعاً، اختيارات المول).
     - بطاقة المنتج الموحدة (Product Card): صورة واضحة، اسم العلامة التجارية، عنوان المنتج بسطرين، السعر الحالي بالجنيه المصري (ج.م)، السعر الأصلي وشارة الخصم المحسوبة الحقيقية، زر إضافة إلى السلة السريع، وزر المفضلة.
     - شريط ثقة وتواصل مباشر عبر واتساب، ومعلومات التوصيل والضمان.

### 2. البنية التكنولوجية المقترحة (Proposed Stack & Architecture)

- **واجهة المستخدم والفرونت إند:** React 18 / 19 + TypeScript + Vite + Tailwind CSS + Lucide Icons + React Router.
- **التوجيه (Routing):** Client-Side Routing كامل وشامل لجميع مسارات المتجر ولوحة الإدارة مع حماية الصلاحيات.
- **قاعدة البيانات والباك إند:** Supabase PostgreSQL + Row Level Security (RLS) + Storage Buckets للميديا والملفات المرفوعة، مع طبقة خدمة بيانات محلية هجينة ومخزنة تدعم العمل المتكامل الفوري مع أو بدون ربط مفاتيح Supabase السحابية في البيئة المحلية.
- **مخطط الأقسام الثمانية المعتمدة لـ مول المصطفى:**
  1. المنزل والتنظيف (Household & Cleaning)
  2. الإلكترونيات وإكسسوارات الموبايل (Electronics & Mobile Accessories)
  3. المكتبي والمدرسي (Office & School Supplies)
  4. الألعاب والهدايا (Toys & Gifts)
  5. الشنط (Bags & Backpacks)
  6. الإكسسوارات (Accessories & Fashion Jewelry)
  7. التجميل والعناية الشخصية (Beauty & Personal Care)
  8. مركز الطباعة المخصص (Dedicated Printing Center)

### 3. خطة ومراحل التنفيذ (Implementation Phases)

1. **المرحلة 0: الفحص والتخطيط المعماري (تم إنجازها).**
2. **المرحلة 1: التأسيس ونظام التصميم (Foundation & Design Tokens):**
   - تثبيت حزم Vite و React و Tailwind و TypeScript.
   - بناء رموز التصميم (Tokens)، دعم RTL، الألوان، والخطوط.
   - إدراج شعار مول المصطفى الفيكتوري الأصيل.
3. **المرحلة 2: مخطط قاعدة البيانات ونظام الأمان (Database, Migrations & RLS):**
   - كتابة وتوليد ملفات ترحيل SQL الكاملة في `supabase/migrations/`.
   - إعداد جداول المنتجات، الفئات، الطلبات، مركز الطباعة، العروض، المستخدمين، والإعدادات.
4. **المرحلة 3: بناء متجر مول المصطفى الكامل (Storefront Implementation):**
   - الهيدر المزدوج وميجا منيو الفئات والبحث الذكي الموحد.
   - الصفحة الرئيسية بجميع أقسامها القابلة للتخصيص من لوحة الإدارة.
   - صفحات الفئات والتصفية المتقدمة (Filters, Sorting, Attributes).
   - صفحة تفاصيل المنتج (Gallery, Variants, Specs, Add to Cart).
   - سلة المشتريات وصفحة إتمام الطلب (Checkout) ببيانات المحافظات والعناوين المصرية.
5. **المرحلة 4: مركز الطباعة المتخصص (Dedicated Print Center):**
   - كتالوج خدمات الطباعة (طباعة مستندات، أبحاث، كروت، فلكس، استيكرات، إلخ).
   - محرك حساب الأسعار وطلب عروض الأسعار التفاعلي.
   - رفع الملفات الآمن وتوليد رقم التتبع ومتابعة الحالة.
6. **المرحلة 5: لوحة الإدارة الشاملة (Complete Admin Dashboard):**
   - لوحة إحصائيات متكاملة واقعية.
   - إدارة المنتجات، الفئات، الماركات، والمخزون مع سجل الحركات.
   - إدارة الطلبات وتغيير الحالات وسجل التاريخ.
   - إدارة طلبات الطباعة وعروض الأسعار والملفات.
   - إدارة البانرات والصفحات التعريفية والإعدادات وطرق الدفع والشحن.
7. **المرحلة 6: الفحص وضمان الجودة والتوثيق (Verification, Testing & QA):**
   - التحقق من خلو الكود من الأخطاء والتحقق من البناء (`npm run build`).
   - اختبار التجاوب مع جميع مقاسات الشاشات (Mobile 360px, Tablet 768px, Desktop 1280px+).
   - كتابة حزمة الوثائق الكاملة.
